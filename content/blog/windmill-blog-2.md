## Getting Started with Windmill - Developer Automation

Windmill is an open-source developer platform for turning scripts into internal tools, APIs, and complex automated workflows. Unlike Zapier or n8n which focus on API connectivity via visual nodes, Windmill is deeply developer-centric. It allows you to write raw Python, TypeScript, Go, or Bash script...

### Installation

```
curl -sL https://github.com/windmill-labs/windmill/releases/latest/download/docker-compose.yml > docker-compose.yml && docker-compose up -d
```
